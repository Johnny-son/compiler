## 1. 当前已经实现的优化

当前 `-O1` IR 管线顺序：

```text
Verify
  -> SimplifyCFG
  -> Mem2Reg
  -> SingleStoreAlloca
  -> InlineSimpleFunction
  -> RuntimeMemoize
  -> TailCallOpt
  -> ConstantFold
  -> LocalCSE
  -> LocalStoreForward
  -> DLE
  -> DSE
  -> SimplifyCFG
  -> TrivialPhi
  -> SimplifyCFG
  -> LoopCanonicalize
  -> LoopClosedForm
  -> SimplifyCFG
  -> LICM
  -> LocalCSE
  -> LocalStoreForward
  -> DLE
  -> DSE
  -> DCE
```

当前优化能力汇总：

| 层级 | 已有内容 | 判断 |
| --- | --- | --- |
| CFG/SSA | `SimplifyCFG`、`Mem2Reg`、`TrivialPhi`、loop preheader/dedicated exit 子集 | 基础稳定，但没有完整 LoopSimplify、LCSSA、LoopRotate |
| 标量优化 | `ConstantFold`、value-numbered `LocalCSE`、普通 `DCE` | CSE 已能沿支配树复用纯表达式，但 DCE 只删无 use 指令，缺 ADCE |
| 内存优化 | `SingleStoreAlloca`、`LocalStoreForward`、`DLE`、`DSE`、保守 `MemoryAlias` | 对 exact/base+offset 有效果；缺 InlineStore、循环内存标量替换 |
| 循环优化 | `LoopCanonicalize`、`LoopClosedForm`、`LICM` | 已有窄模式闭式化，缺通用 SCEV 地址递推和成本模型 |
| 函数优化 | 小纯函数 inline、重叠递归 memo、self tail call 转循环 | 已打掉递归大热点；缺 late inline 和 inline 后 cleanup 闭环 |
| 后端优化 | GPR 图着色、`s1-s11`、copy coalescing、Phi register lowering、compare-branch fusion、local value cache、GEP prefix cache | 后端承接能力较早期强很多；缺独立 RV StrengthReduction/InstCombine/RvDCE |
| 可观测性 | `IRPassManager` 记录 pass 前后 IR 规模，`MINIC_IR_PASS_STATS` 可输出统计 | 已具备后续 cleanup 门控基础，但尚未把统计用于优化取舍 |

## 2. hy 已实现的关键优化

参考项目：`Testing/Hycompiler`。

重点 pipeline：

```text
structured pre-opt
  -> FlattenCFG
  -> GVN/DCE/Inline
  -> Mem2Reg
  -> Alias/DSE/DLE/GVN
  -> CanonicalizeLoop/LoopRotate/LICM/ConstLoopUnroll/SCEV/ADCE/GVN
  -> RegularFold/DCE/GVN/SimplifyCFG/Alias/DSE/DLE/Select/GCM/ADCE
  -> LateInline
  -> InlineStore/SynthConstArray/GCM/GVN
  -> 3 rounds of CanonicalizeLoop/LICM/SCEV/RemoveEmptyLoop/GVN/Fold
  -> Final ADCE/SimplifyCFG/InstSchedule
  -> RISC-V Lower/StrengthReduct/InstCombine/RvDCE/GVN/RegAlloc
```

hy 对照出的关键差距：

| 大类 | hy 做法 | 当前差距 | 本轮判断 |
| --- | --- | --- | --- |
| Cleanup 闭环 | 大优化后多轮 `GVN/Fold/ADCE/SimplifyCFG` | 当前只有固定两段 cleanup，缺 ADCE | 本轮优先做窄 ADCE，避免后续优化产物堆积 |
| GVN | 支配树 value numbering，配合 ADCE | 当前 LocalCSE 已有 value number，但 phi/死环清理不足 | 本轮不重写 GVN，先补 cleanup |
| 循环/SCEV | LoopRotate、SCEV、ConstLoopUnroll、多轮 loop cleanup | 当前缺通用 SCEV；历史裸上容易回退 | 暂缓完整 SCEV，先做可控的低风险后端/cleanup |
| 内存优化 | Alias/DSE/DLE 多轮、InlineStore、SynthConstArray | 当前内存优化保守，跨块和循环内标量替换缺失 | 暂缓高风险内存标量替换 |
| LateInline | 较高阈值 late inline 后继续 cleanup | 当前只有前期小纯函数 inline | 本轮作为候选，需用性能决定是否保留 |
| RISC-V 后端 | StrengthReduct、InstCombine、RvDCE | 当前规则散落在 selector，除模降强仍浅 | 本轮选择安全的 2 的幂除模降强子集 |

## 5. 暂缓项

| 优化 | 暂缓原因 |
| --- | --- |
| 完整 SCEV 地址递推 | 历史候选在后端压力不足时明显回退；当前先补 ADCE 和 RV 降强，再根据热点决定是否小范围追加 |
| 全函数 LCSSA / LoopRotate | 历史 LCSSA 导致 timeout；只能作为某个具体 SCEV/A1 候选的按需修补 |
| GCM | 历史上拉长 live range 后回退；没有寄存器压力模型前不做 |
| 循环内存标量替换 | alias、exit 写回和寄存器压力风险高，放到 SCEV/ADCE 稳定后 |
| 裸 MachineDCE / offset combine | 历史机器 cleanup 子集有负优化；本轮不裸上 |

### B1 窄 ADCE cleanup

状态：已完成并保留。

实现摘要：

- 新增 `ADCEPass`，采用 mark-and-sweep。
- live seed 只包括 terminator、`store`、`call`、`return` 等必须保留语义的指令。
