当前优化能力汇总：

| 层级 | 已有内容 | 判断 |

| 可观测性 | `IRPassManager` pass 规模统计、`MINIC_IR_PASS_STATS` | 可用于后续判断，但本轮仍按性能 CSV 做最终取舍 |

## 2. hy 已实现的关键优化

参考项目：`Testing/Hycompiler`。

hy 的关键链路：

```text
structured pre-opt
  -> FlattenCFG
  -> GVN/DCE/Inline
  -> Mem2Reg
  -> Alias/DSE/DLE/GVN
  -> CanonicalizeLoop/LoopRotate/LICM/ConstLoopUnroll/SCEV/ADCE/GVN
  -> RegularFold/DCE/GVN/SimplifyCFG/Alias/DSE/DLE/Select/GCM/ADCE
  -> LateInline
  -> InlineStore/SynthConstArray/GCM/GVN
  -> repeated CanonicalizeLoop/LICM/SCEV/RemoveEmptyLoop/GVN/Fold
  -> Final ADCE/SimplifyCFG/InstSchedule
  -> RISC-V Lower/StrengthReduct/InstCombine/RvDCE/GVN/RegAlloc
```

对照后的关键差距：

| 大类 | hy 做法 | 当前差距 | 本轮判断 |
| --- | --- | --- | --- |
| helper / inline | `EarlyInline`、`Inline`、`LateInline` 后多轮 cleanup | 当前小 inline 不允许 load，因此 `hash(k){return k%hashmod;}` 这种热点 helper 仍保留 call | 本轮做只读全局标量 load helper inline，边界比 late inline 窄 |
| RISC-V StrengthReduction | 后端有独立 `StrengthReduct`/`InstCombine` | 当前 selector 只有零散规则；`many_mat_cal` 热循环仍有 `divw / 3` | 本轮只做 `/3` 常量除法降强，不重复 perf8 回退的完整 pow2 div/rem |
| Loop/SCEV | `LoopRotate`、`SCEV`、`ConstLoopUnroll` 和多轮 cleanup | 当前缺通用 SCEV；历史裸 SCEV/LCSSA/LoopRotate 容易回退或 timeout | 暂缓，等本轮低风险项后再复查 |
| 内存标量替换 | `InlineStore`、`SynthConstArray`、循环内存优化 | 当前 DLE/DSE 保守，矩阵/stencil 仍重访存 | 暂缓，风险在 alias 和 exit 写回 |
| GCM/调度 | 基于 loop depth 的 GCM | 当前历史回退，容易拉长 live range | 暂缓 |

## 4. 本轮执行清单

| 阶段 | 优化项 | 优先级 | 实现思路 | 预计收益 | 风险与取舍 |
| --- | --- | --- | --- | --- | --- |
| F1 | 只读全局标量 load 小 helper inline | P0 | 扩展 early inline：允许单块、小体量、无 store/call 的函数内联，load 仅限全局标量；目标命中 `hash(k){return k%hashmod;}`，避免保留热 call | 1%-4%，重点 `shuffle1`，也可能减少 call-live spill | 若扩大到内存 load 导致矩阵/crypto 回退，立即收窄或撤回 |
| E1 | RISC-V `/3` signed division strength reduction | P0 | 在 selector 中只把 `sdiv x, 3` 和 `sdiv x, -3` 降为 `mul + srai + subw` 的向零取整序列，新增 `srai` 机器指令；不做通用 magic division | 2%-8%，重点 `many_mat_cal-*` 的大循环 `/3` | 语义必须覆盖负数；若多指令序列放大寄存器压力且总分不升则撤回 |
| 复查 | 根据最新 CSV 追加必要项 | P1 | 每完成一项后复查热点；只有能影响多个热点组且不重复历史回退的方案才追加 | 不预设 | SCEV/内存标量替换若仍是唯一大缺口，放入后续文档或追加小范围实验 |

## 5. 暂缓项

| 优化 | 暂缓原因 |
| --- | --- |
| 完整 SCEV 地址递推 | 历史候选容易增加临时值和寄存器压力；当前先做 `/3` 与 helper inline 两个低风险高命中项 |
| 全函数 LCSSA / LoopRotate | 历史 LCSSA 导致 timeout；只能为具体 SCEV/A1 候选按需构造 |
| 循环内存标量替换 | alias、exit 写回和寄存器压力风险高，当前没有足够成本模型 |
| GCM | 历史上拉长 live range 后回退 |
| 完整 pow2 div/rem 降强 | perf8 三轮不达预期，源码已撤回 |
| Late pure inline | perf8 明显回退，本轮只做更窄的全局标量 load helper inline |
| 常量乘法 shift-add 降强 | perf8 明显回退，不重复 |
